# actor-analyser

Визуализатор акторной активности для просмотра trace-файлов YDB.

Проект предназначен для локального анализа: он читает бинарный или текстовый лог акторной системы, раскладывает акторов по слоям, показывает передачу сообщений во времени и помогает быстро находить нужные акторы и цепочки сообщений.

## Возможности

- загрузка trace-файла;
- визуализация акторов, сообщений и направлений отправки;
- проигрывание timeline вперед и назад с разной скоростью;
- фильтрация акторов по типам;
- поиск актора по имени или `#id`;
- центрирование камеры на найденном акторе;
- tooltip по актору и сообщению;
- построение chain view для выбранного сообщения;

## Сборка

Требования:

- macOS;
- CMake;
- Xcode Command Line Tools.

```bash
git clone <repo-url>
cd actor-analyser
cmake -S analyser -B build-analyser
cmake --build build-analyser
open build-analyser/analyser.app
```

## Запуск И Открытие Trace

При запуске приложение пытается открыть trace по умолчанию:

```text
data/actors_trace_single_v4.bin
```

Если файла нет, приложение не закрывается: будет показан пустой экран с подсказкой открыть файл.

Открыть другой trace:

```text
Cmd+O
```

После выбора файла визуализация перезагружается в текущем окне. В верхней части экрана показывается имя текущего trace.

## Управление

| Действие | Клавиши / Мышь |
| --- | --- |
| Открыть trace | `Cmd+O` |
| Поиск актора | `Cmd+F` |
| Выбор совпадения в поиске | `Tab`, `Shift+Tab`, стрелки вверх/вниз |
| Перейти к найденному актору | `Enter` |
| Закрыть поиск | `Esc` |
| Перемещение камеры | drag мышью или стрелки |
| Масштаб | колесо мыши, `+`, `-` |
| Пауза / продолжить | пробел |
| Скорость | `1`..`0`, `Shift` меняет направление |
| Адаптивный режим времени | `A` |
| Сокращенные имена сообщений | `S` |
| Фильтр типов акторов | панель справа, `H` скрыть/показать |
| Chain view для сообщения | `Ctrl`/`Cmd` + click по сообщению или `C` над сообщением |
| Debug overlay | `F1` |

## Данные

Сейчас поддерживаются:

- бинарные trace-файлы нового формата;
- старый текстовый формат логов.

Файл `analyser/data/actor_types_map.config` используется для переименования типов акторов. Файл `analyser/data/seet.config` задает группировку акторов по слоям.

## Ограничения

- сбор логов с разных нод и их склейка не реализованы;
- часть логики анализа ориентирована на локальный trace;
- chain view полезен для исследования причинно-следственных связей, но не является полноценным профилировщиком;
- интерфейс рассчитан на desktop/macOS.
